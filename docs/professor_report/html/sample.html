Problem

A client without class c still sends its row wc. That copy only shrinks (weight decay), so the average pulls the real row toward zero.

⌖
Where

Server, Stage II, every round. Only the 10 label rows change; all other weights are averaged as before.

↻
Change

Average row c only over clients that have class c, weighted by how many samples they hold.

wc ← Σk E(nkc) · wc(k)Σk E(nkc)   E(n) = effective sample count, E(0) = 0
✓
Why it helps

A client that never saw class c can no longer pull its row down. Cost: only per-class counts, sent as sums.
