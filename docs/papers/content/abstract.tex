Federated learning across clients that run different model architectures and hold long-tailed, skewed label
distributions loses most of its accuracy on rare classes. We study generator-based model-heterogeneous federated
learning, where clients share a frozen extractor and a federated conditional feature generator, and each architecture
trains its own head. We trace the loss to three places: Adam with coupled
weight decay shrinks the generator's class-specific parameters on clients that lack a class; each head's last layer
is fitted to one client's label prior; and synthetic features that do not carry their label penalise the spread of
the logits. We propose FedECS-LT, which replaces each of these estimates by an exact class statistic computed
under secure aggregation: a mean-anchored generator, class-count weighted averaging when classes are poorly
separated, moment correction of generated features, logit-adjusted heads trained on consensus soft labels, and a
class-balanced readout computed from aggregated sums. With ten client architectures, FedECS-LT reaches
\R{main/cifar10/FedECS-LT/bal} balanced accuracy on CIFAR-10-LT and \R{main/cifar100/FedECS-LT/bal} on CIFAR-100-LT,
\R{main/cifar10/margin} and \R{main/cifar100/margin} points above the strongest of \R{main/nbaselines_w} other methods
(paired tests: significant on CIFAR-100-LT, not on CIFAR-10-LT); when every method is given the same exact readout,
the margins shrink to \R{main/cifar10/er_margin} and \R{main/cifar100/er_margin} points and are not significant. It also has the highest balanced accuracy on \R{nat/nbest_of}
datasets with natural class imbalance. With one model shared by all clients, end-to-end long-tail
methods are stronger. All methods share the same client splits.
